# Contributing

Thank you for your interest in contributing!

## 📐 This Repo

This repo is the scraper for MAIRON GALATI SA (CIF 6581999) in the peviitor.ro ecosystem. It publishes jobs scraped from the company's public eJobs.ro company page to peviitor.ro.

## Development Setup

```bash
npm install
npm test
```

## Reporting Issues

Open a [GitHub Issue](https://github.com/peviitor-scrapers/mairon-galati-sa-nodejs-scraper/issues) with:
- Clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
